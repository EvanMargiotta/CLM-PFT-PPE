# CLM-PFT-PPE

This repository accompanies Margiotta et al. (2026) and contains the code neccessary for the analysis and plotting found in the paper. The jupyter notebook here directions to directly reproduce the results and plots found in the main text of the paper. For convenience, the code for reproduction has been split up between 5 notebooks spanning data preparation, analysis, and plotting.

The full CLM-PFT-PPE dataset is availible at https://doi.org/10.5281/zenodo.17178817. This dataset contains all model output from the 500-member PPEs. While users interested performing their own analysis may be interested in the entire dataset, several smaller subsets are availible in this repository suitable for results reproduction analysis alone.
